# Assembly Mode — 100-Puzzle Working Backlog

Status: WORKING PROJECT PLAN  
Purpose: future Assembly-mode content after the current five prototype puzzles.

## Duplicate-screening rule

This backlog was checked against all 565 current Clue Canvas answers in `src/data/puzzles.ts`, plus the five current Assembly prototype answers:

- A Watched Pot Never Boils
- Jump Through Hoops
- Burn the Midnight Oil
- When It Rains It Pours
- All Roads Lead to Rome

The 100 concepts below have no exact answer collision and no strong token-overlap match with the existing catalogue. Before artwork production, each item must still receive the normal semantic/visual duplicate review required by `docs/10_ASSEMBLY_PREMIUM_ART_STANDARD.md`.

## Content mix

- 90 idioms / sayings / proverbs
- 10 "Guess the Movie" visual puzzles
- Movie puzzles should use title-level visual clues and generic cinematic motifs rather than copied logos, posters, or recognisable actor/character likenesses.
- Assembly gameplay should stay inside the standard Clue Canvas puzzle-screen layout.
- Difficulty should come from piece count, rotations, composition, misleading-but-fair visual detail, move efficiency, and phrase inference — not from hiding basic controls.
