# The Last Page

A mobile-first standalone concept for the phrase **the year dot**. It does not modify or import the production game.

Tap the calendar repeatedly. Each interaction removes a larger burst of pages and carries the displayed year further into the past. After year 1, the last page contains only a dot. Enter `the year dot` to complete the puzzle.

Open `index.html` directly or double-click `OPEN_YEAR_DOT_CALENDAR.bat`.
