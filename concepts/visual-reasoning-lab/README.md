# Clue Canvas — Visual Reasoning Lab

This is the second private, local-only concept lab. It explores three adult visual-reasoning game systems and an unlockable weekly bonus. It does not import production code, connect to an account, send analytics, or call a backend.

## Included

1. **Connection Board — Live Current:** sort twelve ambiguous evidence plates into three four-card groups, name each shared word, then connect all three groups.
2. **Visual Logic — The Meridian Matrix:** solve a precise 3×3 matrix governed by frame, contact-count and spoke-combination rules.
3. **Investigation Room — The Conservator’s Study:** inspect a coherent room, collect and use physical evidence, open a sealed safe, then identify the authentic folio.
4. **Weekly Bonus — The Midnight Vault:** use the three earned tools in one integrated optical-routing set piece.

Completing all three prototype games unlocks the bonus. The eventual production threshold can be tuned independently. A discreet lab control allows the bonus to be previewed without changing completion progress.

Progress is saved only in this browser under `cluecanvas.visualReasoningLab.v1`.

From Windows, the easiest launcher is `OPEN_PREMIUM_REASONING_LAB.bat` in the main Desktop `Rebus` folder.
