# Clue Canvas — Case 01: The Counterfeit Room

A self-contained vertical-slice prototype for the proposed deeper Clue Canvas mode.

## Design goal

This is not an animated rebus and not a collection of unrelated mini-games. It is one linked case in which information discovered earlier is required later.

Flow:

1. Survey six objects in the conservator's room.
2. Mark the three observations that are genuinely useful.
3. Reconstruct the shipment timeline.
4. Use the reconstructed evidence to calibrate the inspection lamp.
5. Inspect four candidate prints under the calibrated lamp.
6. Identify the authentic print and explain why.

The prototype includes progressive hints, wrong-answer feedback, local progress, reset, accessibility labels, mobile layout and a completion debrief. It intentionally does not connect to production data or accounts.
