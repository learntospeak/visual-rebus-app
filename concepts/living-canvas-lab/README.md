# Clue Canvas — Living Canvas Lab

This is a private, local-only concept prototype. It is deliberately isolated from the production app: it has no account, backend, analytics, network calls, or production data imports.

## Open it

The quickest option on Windows is to double-click `OPEN_LIVING_CANVAS_PROTOTYPE.bat` in the main Desktop `Rebus` folder. You can also use `OPEN_LIVING_CANVAS.bat` here (or open `index.html` directly). Everything required by the prototype lives in this folder.

For the same browser environment as the app, run `npm run dev` from the `visual_rebus_app_project` folder, then open:

`http://localhost:5173/concepts/living-canvas-lab/`

Progress is stored only in this browser under `cluecanvas.livingCanvasLab.v1`. Use **Reset prototype** in the footer to clear it. **Preview finished canvas** changes the artwork preview only; it does not mark games complete.
